# ADR-0012: Testcontainers Replaces H2 for Integration Tests

**Status**: Accepted  
**Date**: 2024-08-06

## Context

v1 integration tests (`SmokeIT`) used H2 in MySQL compatibility mode (`MODE=MySQL;NON_KEYWORDS=USER`) as a lightweight database substitute. While H2 worked for basic CRUD, it diverged from MySQL 8.4 in subtle ways (e.g., `DATETIME(3)` precision, JSON handling, `ON DUPLICATE KEY UPDATE` semantics, and reserved-word behavior).

## Decision

Replace H2 with **Testcontainers MySQL 8.4** for all integration tests. The `application-test.properties` profile now points to a Docker-managed MySQL instance with the exact same version as production.

## Consequences

### Positive
- **Production parity**: tests run against the same MySQL 8.4 version as production, catching dialect-specific bugs.
- **Flyway migrations tested end-to-end**: V1 + V2 migrations execute against a real MySQL instance during tests.
- **Orphan semantics verified**: deleted devices' historical data is queryable in tests, matching production behavior.

### Negative
- **Docker dependency**: CI runners must have Docker available. If not, integration tests are skipped (configured in CI workflow).
- **Slower test execution**: spinning up a MySQL container adds ~5-10s to test startup.
- **Local dev friction**: developers without Docker cannot run integration tests locally (unit tests still work).

### Neutral
- `SmokeIT` continues to use `@SpringBootTest` with `@ActiveProfiles("test")`; only the datasource changes.
- ArchUnit tests remain Docker-free (they don't need a database).
- The `aluco-server` CI job in GitHub Actions uses `services: mysql` to provision the test database.

## CI Configuration

```yaml
services:
  mysql:
    image: mysql:8.4
    env:
      MYSQL_ROOT_PASSWORD: test
      MYSQL_DATABASE: aluco
    ports: ["3306:3306"]
    options: >-
      --health-cmd="mysqladmin ping"
      --health-interval=1s
      --health-timeout=5s
      --health-retries=20
```

## Test Profile

```properties
# src/test/resources/application-test.properties
spring.datasource.url=jdbc:mysql://localhost:3306/aluco?useSSL=false
spring.datasource.username=root
spring.datasource.password=test
spring.flyway.enabled=true
aluco.mqtt.enabled=false
aluco.offline.enabled=false
```
